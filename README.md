# Gamma Vendor (Universal)

Этот репозиторий — универсальный шаблон для w2a (Web-to-App). Он позволяет скачать **любой** сайт, сгенерированный в Gamma, со всем его React-рантаймом и запустить его локально.

## Как использовать:

1. Нажмите **Use this template** (зеленая кнопка) и создайте новый репозиторий для вашего сайта.
2. Перейдите во вкладку **Actions** -> **Universal Vendor** -> **Run workflow**.
3. Введите URL вашего сайта (например, `https://example.gamma.site/`).
4. Дождитесь завершения сборки.

## Как запустить локально (Тест):

```bash
git clone https://github.com/ВАШ_ЮЗЕР/ВАШ_РЕПОЗИТОРИЙ.git
cd ВАШ_РЕПОЗИТОРИЙ
python server.py



## 📱 W2A (Web-to-App) готовность

Этот репозиторий содержит `server.go` — минималистичный HTTP-сервер на Go.

### Как собрать APK для Android:

1. Скомпилируйте Go-сервер:
   `GOOS=android GOARCH=arm64 go build -o server server.go`
2. Положите `server` + `index.html` + `_next/` + `assets/` внутрь APK (в папку `assets/`).
3. При старте приложения распакуйте их и запустите `server` через `ProcessBuilder`.
4. Откройте `http://127.0.0.1:8080` в WebView.

### Преимущества:
- **Офлайн.** Работает без интернета.
- **Приватность.** Privacy Shield удаляет все трекеры.
- **Скорость.** React-рантайм загружается с локального диска.
