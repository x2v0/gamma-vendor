# Gamma Vendor (Universal)

Этот репозиторий — универсальный шаблон для w2a (Web-to-App). Он позволяет скачать **любой** сайт, сгенерированный в Gamma, со всем его React-рантаймом и запустить его локально.

## Как использовать:

1. Нажмите **Use this template** (зеленая кнопка) и создайте новый репозиторий для вашего сайта.
2. Перейдите во вкладку **Actions** -> **Universal Vendor** -> **Run workflow**.
3. Введите URL вашего сайта (например, `https://example.gamma.site/`).
4. Дождитесь завершения сборки.

## Как запустить локально (Тест):

```bash
